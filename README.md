# B1 Numerical Algorithms

MATLAB mini-project applying numerical algorithms to a noisy sensor signal.

## Run

1. Open MATLAB and `cd` to this folder.
2. Run:

   ```matlab
   main
   ```

`main.m` adds all subfolders to the path and seeds `rng(1)`, so results are reproducible.

## Contents

- **Part A** – numerical differentiation
- **Part B** – polynomial approximation
- **Part C** – ODE solvers (Euler, RK4)
